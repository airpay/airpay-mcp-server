# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅        |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Email: **security@airpay.in**

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

Expected response: acknowledgement within 48 hours, fix timeline within 14 days for critical issues.

## Scope

- Credential handling and encryption pipeline
- OAuth2 token management
- MCP tool input validation
- Any code path that processes payment data
